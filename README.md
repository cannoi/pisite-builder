# PiSite Builder

Trình tạo website trực quan chuyên nghiệp dành cho doanh nghiệp và dịch vụ, hỗ trợ người dùng không biết lập trình chọn template, chỉnh sửa nội dung trực tiếp, xem trước và xuất bản.

## Tính năng
- Thư viện template Trang doanh nghiệp và Dịch vụ
- Trình chỉnh sửa trực quan realtime
- Chế độ xem trước Desktop & Mobile
- Lưu trữ SQLite tại chỗ
- Xuất bản mã nguồn HTML/CSS hoàn chỉnh
